PORTFOLIO TEMPLATE — BLUE EDITION

This is a clean template based on the original portfolio layout. Personal names, contact details, project images, logos and videos have been removed/replaced with placeholders. The main accent color is blue.

QUICK START
1. Open index.html in a browser.
2. Replace YOUR NAME, YOUR BIO, email, social links and WhatsApp/phone link.
3. Replace the placeholder images inside assets/images/ with your friend's images. Keep the same filenames to avoid changing HTML.
4. Add project videos inside assets/videos/ and put their filenames into the data-video attributes in index.html.
5. Replace PROJECT TITLE and photography project headings with the real project names.
6. For hosting, upload the whole folder to Netlify, Vercel, GitHub Pages or another static host.

IMPORTANT
- index.html is the main page.
- index-onepage.html is the alternate one-page version.
- The original visual layout and responsive structure are preserved.
